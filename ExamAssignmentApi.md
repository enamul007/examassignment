# Project Overview (`ExamAssignmentApi`)
* **Framework:** .NET 8.0 with Nullable & Implicit Usings enabled.
* **Database & ORM:** PostgreSQL (`Npgsql.EntityFrameworkCore.PostgreSQL`) via EF Core 8.
* **Authentication:** JWT Bearer token authentication.
* **Security:** Password hashing using `BCrypt.Net-Next`.
* **API Documentation:** Swagger/OpenAPI via Swashbuckle.
